# Team Question Flow

## First Round

Ask only these three questions unless the answer already exists:

1. Which team or department is involved, and who is the contact responsible for this interface?
2. What deliverable, decision, access, or review must they provide or receive?
3. When is it needed, and is the current status confirmed, planned, blocked, or unknown?

## Follow-up Only When Needed

| Gap | Question |
| --- | --- |
| No acceptance rule | What makes the team's deliverable acceptable to the next WBS stage? |
| Update is stale | Which channel and cadence should confirm this interface? |
| Escalation unclear | Who can resolve a blocked handoff or priority conflict? |
| Impact unclear | Which milestone moves if this team is late? |

## Writing Rules

- Use one stable team slug and keep it consistent in `teams/index.md`.
- Link dependencies to a team file and source evidence where available.
- Keep raw meeting evidence under `raw/`; the team file is current context, not a replacement for source evidence.

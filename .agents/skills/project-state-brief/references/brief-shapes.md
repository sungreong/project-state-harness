## Weekly Brief

Add a `Plan vs Actual` table, decisions needed, changed dependencies, and sources that became stale.

## Scenario: Executive-style Status Is Requested

State the current stage, material risk, and requested decision in plain language. Keep detailed evidence links in the final section.

## Scenario: Developer Needs a Starting Point

List only work marked ready. For each not-ready item, name the missing contract, decision, or acceptance condition rather than a vague warning.
